# SpecLino MCP 開発ガイド

SpecLino MCP サーバーの各種ツールを活用し、仕様作成から実装・検証までを安全に進めるためのワークフローおよび利用ガイドです。

## MCPツール利用ガイド

- **仕様作成機能の活用**
  - 仕様作成・編集用のツールを用いて、要件や受け入れ基準を構造化して記述する。
  - 既存の仕様（`spec:*`）との重複や矛盾がないか、作成前に既存知識を参照して確認する。
- **ツールの使い分け**
  - 仕様・指示書の確認: 関連する仕様や共通指示（`instructions:*`）の参照用ツールを優先して使い、前提知識を把握する。
  - 変更と検証: コード変更やテスト実行など、目的に合致した最小限のツールを順序立てて呼び出す。
- **呼び出し時の注意点**
  - 一度に大きな変更を行わず、ステップごとにツールの実行結果を確認して進める。
  - 仕様の作成・更新時は、利用者が差分を確認しやすいように変更意図を明確にする。
- **推奨プロンプト/指示の書き方**
  - 「どの仕様に基づいて」「どのツールをどのような順序で使うか」を明示する。

## 主な開発の流れ

1. **現状確認・仕様の参照**
   - 対象リポジトリの関連仕様（`spec:*`）や指示書を確認します。
   - 必要な MCP ツール（仕様取得、ファイル参照など）を用いてコンテキストを把握します。

2. **仕様の作成・整理**
   - 新規機能や変更要求に応じた仕様（Spec）を SpecLino の仕様作成機能を用いて作成・下書きします。
   - ゲート条件や受け入れ基準、前提条件を明確に落とし込みます。

3. **実装と検証**
   - 定義した仕様に基づき、提供されているツールを用いて実装作業を行います。
   - テストや検証ツールを実行し、仕様を満たしているか確認します。

4. **記録・報告**
   - 変更点やテスト結果を整理し、利用者に差分と確認事項を提示します。

# デモ動画の台本（2 分 54 秒）

動画: https://youtu.be/Ng_zdjhMiyg

対象: 第5回 Agentic AI Hackathon with Google Cloud の審査員。伝えること:
「チームがエージェントに渡す知識を SpecLino で管理し、各自のエージェントに配り、エージェントが書いたものも人の承認とゲートで守られる」。

- 画面は LP、本番の SpecLino、Antigravity（利用者のコーディングエージェント。MCP で SpecLino につなぐ）、GitHub の PR
- 構成は LP の「エージェントの仕組み」に合わせる（あなたのコーディングエージェント・執筆エージェント・調査エージェント・チームの人）
- デモ PR 3 本:
  [#1](https://github.com/tanabe-yudai/speclino/pull/1)（デモ1: 図に違反・反例）、
  [#2](https://github.com/tanabe-yudai/speclino/pull/2)（デモ2: 仕様の写しの改変を lock で止める）、
  [#3](https://github.com/tanabe-yudai/speclino/pull/3)（デモ3: 解析できないループで UNKNOWN → 失敗、調査エージェントが動く）

## 撮影のメモ

- 4〜6 の Antigravity への依頼は、ツール名を書かず、利用者が頼むような大まかな指示にする。待ち時間は編集で早送りする
- 5 で承認した仕様は、撮影後に取り下げる（リポジトリに当たる知識を元に戻し、lock とゲートに影響させない）
- 画面にトークン・メールアドレスを映さない（承認画面の作成者のメールアドレスはぼかす）
- 字幕は判定の語を画面と同じにする（適合 / 違反 / 未検証 / 要確認）

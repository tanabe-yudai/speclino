# デモ動画の台本（3 分）

対象: 第5回 Agentic AI Hackathon with Google Cloud の審査員。伝えること:
「チームがエージェントに渡す知識を SpecLino で管理し、配り、守られていることをゲートで保証し、観測できる」。

- 画面は本番の SpecLino（ログイン済みのテストアカウント）と、GitHub の PR、手元のエディタ（Claude Code）の 3 つ
- 題材はこのリポジトリ自身の仕様（俯瞰の仕様 7 本）と、デモ PR 3 本:
  [#47](https://github.com/tanabe-yudai/spec-lino/pull/47)（デモ1: 図に違反・反例）、
  [#45](https://github.com/tanabe-yudai/spec-lino/pull/45)（デモ3: 仕様の写しの改変を lock で止める）、
  [#46](https://github.com/tanabe-yudai/spec-lino/pull/46)（デモ4: 解析できないループで UNKNOWN → 失敗）。
  番号は PR の題に合わせている（デモ2・5 は無い）
- 撮影前に、3 本の PR の検査が最新の main を取り込んだうえで完了していることを確かめる
- 時間は目安。ナレーションは 1 秒あたり 6〜7 文字で数えている

| # | 時間 | 画面 | ナレーション |
| --- | --- | --- | --- |

## 撮影のメモ

- 5〜7 は、PR を開いた直後ではなく検査が終わった状態から撮る（待ち時間を見せない）
- 5 の反例は、検査の詳細の反例（条件 `before.triage.has_findings and not(before.triage.has_mandatory)` で、
  実装は `_pass` を呼ぶ）を拡大する
- 3 で仕様を書き換えたら保存しない（承認済みの仕様を変えない。見せるだけ）
- 4 のエディタの端末に、トークン・メールアドレス・GCP のプロジェクト ID が映らないようにする
  （`SPECLINO_MCP_TOKEN` は事前に環境変数で渡す）
- 字幕は判定の語を画面と同じにする（適合 / 違反 / 未検証 / 要確認）
